口径、偏差与遗留

  1. 确定性口径。DP4 形态下 head 节点多个 API server(SO_REUSEPORT)把请求分派到不同 DP 引擎, 同一 prompt 贪心复测非逐字节一致(既有全能力先例首轮同款已归因);按引擎判确定性需 multi-port 模式(local DP ≥ 2,本形态为 1)。本报告判据 = 功能正确性 + needle 命中。
  2. chat 模板注入。官方权重目录 tokenizer_config.json 不含 chat 模板(实测); 部署侧生成模板副本并以 --tokenizer 覆盖,权重目录零写入。
  3. 跨版本不可横比。0.27 基线 = 纯 BF16、无 Engram、旧模板;本形态多 394 GB host Engram 表与官方模板系统头,TTFT/TPOT 数字含形态差。
  4. RL 同步链未接。0.27 线 reload 热更为旧 API 面,0.30 不兼容;若 0.30 转为 RL rollout 面,需重做权重热更新扩展(独立线)。
  5. 视觉无 OCR/细粒度能力评测。本轮仅验证链路可用与颜色语义,不含图像理解质量评测。
