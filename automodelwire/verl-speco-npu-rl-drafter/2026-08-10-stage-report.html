项目架构与工作原理

系统架构

                verl trainer (8×910B3)
   GSM8K ──► SpecoRay PPO ──rollout──► vLLM-Ascend 0.18 (target + drafter)
                Trainer      ◄──responses──  (EAGLE3 spec decode)

EAGLE3 投机解码工作原理

  • 投机解码: 小 drafter (1层 transformer + fc) 预测主模型 (8B) 下几个 token, 主模型一次验证 draft, 接受的 token 免费获得
  • EAGLE3 特性: 以主模型每层 hidden state 为条件预测 (比只看前 token 更准)
  • 接受率 (mean_acceptance_length): 每 draft 序列平均接受 token 数, >1 即有加速收益

Co-Training 环路

rollout 生成 ──① 每5步收集 hidden──► drafter 训练 (20 opt steps)
      ▲                                      │
      └──────────⑤ 权重发布 ◄──④ 训练完成 ──┘
  • collect_interval=5: 每 5 步收集训练数据 (target hidden + token)
  • training_interval=5: 每 5 步触发 drafter 训练 (20 opt steps, lr=1e-4)
  • publish: 训练后权重经共享内存发布给在线 drafter server, 下轮 rollout 生效
