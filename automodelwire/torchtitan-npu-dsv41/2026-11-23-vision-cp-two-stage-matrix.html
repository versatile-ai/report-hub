阶段① 图片 → token(视觉层) 与 阶段② token → logits(文本层)

读图前的三个总纲(图都在证这三句)

1. 参数分布与 CP 无关。三家完全相同:视觉塔与文本解码器的参数都按数据并行(FSDP)分片,每卡只存 1/N 碎片,某层前向时临时 all-gather 拼全、算完即弃。CP 开不开、开多大,每卡权重占比不变 —— 所以下矩阵里"参数"一行三家同文,不是疏漏,是结论。

2. 阶段①(视觉塔)CP 不进入塔内。塔的输入是图像 patch,没有 token 序列轴可切:三家的塔都整图前向、每卡一份(冗余计算),塔内激活与塔间通信为零。CP 对图像的唯一作用点在塔之后的"特征注入" —— 而注入发生在词嵌入流上,时序上属于两阶段的交界。

3. 阶段②(文本层)才是 CP 的主场。token 半行(或文档段)流经 40 层;为让每段查询看到足够的过去,KV 在每层边界做整行拼装(本方案/BSND)或按窗口窄交换(TND);n-gram 记忆的前驱在边界处有三种拿法。激活减半 = CP 的全部收益,通信 = CP 的全部代价,都在这一阶段。

用一句话回答"CP 在两个阶段如何起作用"

阶段①(图片 → token):CP 只改变"图像特征写进哪半行词嵌入",不改变视觉塔本身 —— 塔的参数照 FSDP 分片、图像照整份复制、塔内激活照整图计算;三家唯一的分歧是注入发生在切分前(BSND)还是切分后(本方案半行 / TND 交集),而这一步都不需要通信。

阶段②(token → logits):CP 把每卡的 token 与激活减半(半行或文档段),为此付出每层一次的 KV 交换 —— 本方案与 BSND 付"整行拼装",TND 付"只交换本段仍可达的行";n-gram 记忆在边界处分别用预构造(零通信)/ 整行哈希切片(零通信)/ 左邻 halo(最小通信)补齐前驱。参数始终走数据并行分片,与 CP 无关。
