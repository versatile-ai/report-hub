四问四答(先结论,图在后)

问题答案
① 输入的权重是几分之几? 每卡三份碎片:稠密权重 1/16(视觉塔 0.8B + 解码器稠密层 + 嵌入,FSDP 沿全部 16 卡切)、MoE 专家 64 个中的 4 个(整份持有,专家并行 16)、n-gram 记忆表 1/16(随专家并行切)。关键:CP 开与不开,权重都是每卡 1/16(CP=1 时沿数据分片 16 单轴;CP=2 时沿数据分片 8 × CP 2 双轴)——CP 省的从来不是权重,是激活。
② 重复的内容有哪些? 只有一类常态复制:图像内容——图像 patch 张量、图像网格表、以及视觉塔输出的特征库,CP 对的两张卡各持完整一份(每卡自己完整跑一遍视觉塔,产出逐位相同)。另有层内瞬态复制:某层前向的一瞬间,全量权重(16 卡拼来)和整行 KV(伙伴半行拼来)临时在场,算完即弃。跨 CP 对之间:无任何重复(每对吃不同样本)。
③ Token 哪些重复、哪些不重复? 切分前:CP 对两卡各持同一条完整序列(重复态)——这正是"切分零通信"的本钱:整行两卡都有,各自本地"重排+切片"即可,不需要传任何数据。切分后(进入前向时):两卡各持一半、互补零重叠,没有任何一个 token 重复。图像占位 token 与文本 token 一视同仁被切,没有豁免——本例中 1024 个图像占位恰好全部落在卡 A,卡 B 一个占位都没有(走空路径,见 图 2)。
④ 切分策略怎么映射到图上? 四步(图 3 逐步画):对齐填充(每篇文档长度补到"并行度×压缩比"的整数倍)→ 按文档分块重排(每篇文档切成 R 等份,第 r 张卡拿每篇的第 r 块;RL 形态一条序列就是一篇文档,重排退化为恒等——前后直切)→ 均分切片 → 簿记随行(位置、标签、token 类型表、图像特征位置表四件与 token 同置换同切,后两件是本方案新增)。
同一节点内配对(卡0↔1、2↔3 …)——注意力的 KV 交换因此不跨节点(上游为此做过专门优化)。 专家派发与记忆查表才跨节点;这两条通信与 CP 无关,开不开 CP 都存在。 配色:■ 切分的权重碎片 ■ 专家/记忆 ■ CP 对(序列轴) □ 普通 NPU 卡
特征注入只发生在卡 0 (从复制区的特征库按位置表取行,写进本卡词嵌入;逐 token 操作,与行序无关) 半行 2432 token,无任何一份与卡 1 重复 ④ 层内瞬态 —— 用时拼全,用完即弃(40 层每层重复一遍) 当前层的全量权重 ← 从 16 卡 all-gather 拼来,算完这一层就丢 本层整行 K/V ← 卡 0 半行 + 卡 1 半行 拼合(节点内交换) 注意力:Q = 本卡半行 × K/V = 整行(只允许看到自己段之前,看不到未来) 卡 1(节点 1)—— CP 对的"后半卡" ① 权重区 —— 切分:每卡只存碎片 稠密权重 1/16 MoE 专家 4/64 个 n-gram 记忆表 1/16 比例与卡 0 相同,但碎片内容不同(互补的另 15 份在其余卡) 前向拼全量时,每卡各贡献自己的 1/16 ② 复制区 —— 与卡 0 完全相同(常态复制) 图像 patch 张量(整张图)+ 图像网格表 特征库 [全部图像特征 × D]本卡自己完整跑一遍视觉塔得出 虽然本卡序列里没有图像占位,塔照跑、特征库照样持有 —— 注入空路径用"乘零"保梯度连通 ③ Token 切分区 —— 与卡 0 互补,拼合才是完整序列 响应后段 2176 填充 位置表 ‖ 标签 ‖ token 类型表 ‖ 图像特征位置表 —— 与卡 0 经同一置换切出的另一半 n-gram 前驱表:同样在切分前预构造成半行 → 本卡 零图像占位:特征注入走空路径(输出 + 特征库总和 × 0) 视觉塔参数的梯度仍然连通、仍被训练(有效贡献全部来自卡 0 的注入位) 半行 2432 token,无任何一份与卡 0 重复 ④ 层内瞬态 —— 用时拼全,用完即弃 当前层的全量权重 ← 16 卡拼来(与卡 0 拼出同一份全量) 本层整行 K/V ← 与卡 0 半行拼合后,两卡各持同一份整行 反向时:KV 拼合自动反演为梯度归并(reduce-scatter),各卡梯度回各卡 互补 · 零重叠
同一个置换,否则特征会写进别的 token(静默错误)。 切分完成后,token 在两卡间无任何重复;常态"重复"的只剩图像内容(图 2 绿区)。
