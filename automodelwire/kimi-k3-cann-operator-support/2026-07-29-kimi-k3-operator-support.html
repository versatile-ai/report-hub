2.2 KDA vs 标准 GDR 差异（关键，决定算子是否可复用）

K3 的 KDA（Key-Dependent Accumulation）是 Gated DeltaNet/DeltaRule 家族的 变体，chunk_kda 调用参数包含标准 GDR 没有的 KDA-specific 项：

chunk_kda(q,k,v,g,beta,
  A_log,               # log A，非 GDR 的 A/g
  dt_bias,             # dt 偏置，GDR 无
  use_qk_l2norm_in_kernel=True,
  use_gate_in_kernel=True,
  use_beta_sigmoid_in_kernel=True,
  safe_gate, lower_bound,  # 门控下界，GDR 无
  transpose_state_layout=True)

证据：modeling_kimi_linear.py:610-627

这意味着 MindSpeed 的标准 chunk_gated_delta_rule bwd（参数 q,k,v,g,beta,scale,initial_state）不能直接用于 K3——缺 A_log/dt_bias/key-dependent beta 的梯度通路。

5. 量化路径分析（分开）

5.1 W4A16-MXFP4（K3 checkpoint 实际路径）

权重 mxfp4 (4-bit e2m1) + 激活 bf16。流程：npu_format_cast(weight, 29, customize_dtype=bf16) → npu_convert_weight_to_int4pack → bf16 matmul。MoE 走 ensure_mxfp4_moe_available 守卫。

  • CANN：aclnnWeightQuantBatchMatmul V1/V2/V3 + Nz（9.0.0/9.0.1 均在）→ 矩阵层支持
  • torch_npu：需 float4_e2m1fn_x2 / float8_e8m0fnu 符号（mxfp_compat.py 注释：2026-03 torch_npu 发布）
  • 训练：不支持 mxfp4 权重量化训练，仅推理
  • SoC：A2+ 可（weight-only，无动态量化融合要求）
推荐推理量化路径：W4A16-MXFP4 与 K3 checkpoint 对齐，权重 4-bit 显存约为 bf16 的 1/2，激活保持 bf16 精度无损。待 torch_npu 符号发布后可直接走 vllm-ascend w4a16_mxfp4 方法。

5.2 W4A8-MXFP4（备选，非默认）

权重 mxfp4 + 激活 fp8 e4m3 动态量化。npu_dynamic_mx_quant(x, dst_type=fp8_e4m3) + npu_quant_matmul(scale_dtype=e8m0fnu, pertoken_scale)。

  • SoC 硬约束：_is_dynamic_mx_quant_fusion_soc_supported() 要求 AscendDeviceType.A5（Ascend950）。A2/A3 不可。
  • torch_npu：需 npu_dynamic_mx_quant + npu_add_rms_norm_dynamic_mx_quant 融合符号
  • K3 不默认走此路径：checkpoint activations=null，仅当用户显式改用动态量化才生效

5.3 W4A4-MXFP4（备选）

权重+激活均 mxfp4，npu_dynamic_mx_quant + npu_quant_matmul 双 mxfp4。同样需 A5 + 新 torch_npu。极致显存但精度损失大。

5.4 bf16（训练 / 推理基线）

无量化，全 bf16。所有算子走标准 aclnn Matmul/RMSNorm/FA。训练除 KDA/MoE/mxfp4 三缺口外其余可训。推理显存最高但兼容性最好。这是当前唯一可立即跑通的训练前向基线。

路径选择建议：推理 → W4A16-MXFP4（对齐 checkpoint，待 torch_npu 2026-03）；训练 → bf16（但受 §6 三缺口限制，仅能做 MLA 层 / 稠密层 / lm_head 局部训练，KDA+MoE 不可训）。

8.2 建议

  1. 推理优先：先做 bf16 推理通路，验证 triton KDA 96 头前向 + MLA + latent MoE + 视觉塔，再切 W4A16-MXFP4 降显存
  2. 不要走 W4A8：K3 checkpoint 是 weight-only mxfp4，W4A8 需 A5 且非默认，误用会引入精度/硬件风险
  3. 不要假设 grouped topk：K3 n_group=1，路由为简单 sigmoid+topk，复用 DeepSeek-V3 grouped 路由代码时跳过该分支
  4. 训练若必须：优先补 KDA bwd triton 核（对齐 fla 上游 KDA bwd）+ 解除 MoE block 禁训 + 退 bf16，工作量集中在 KDA bwd
  5. vllm-ascend 集成：以 patch_kimi_k25.py 为模板写 patch_kimi_k3.py，注册 kimi_linear text backbone + KimiK3ForConditionalGeneration VLM
